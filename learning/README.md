# learning

Standalone experiments that aren't tied to the book or the course: trying a stdlib package, poking at generics, benchmarking something, a snippet worth keeping.

One folder per topic, e.g.:

```
learning/
├── generics/
├── context-cancellation/
├── benchmarks-maps-vs-slices/
└── testing-table-driven/
```

If an experiment grows into something real, move it to [`../projects`](../projects).
